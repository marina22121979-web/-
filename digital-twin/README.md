# Пять навыков для цифрового двойника Марины

Первые три — официальные навыки разработчиков сервисов. Два остальных выбраны для конкретных недостающих задач: клонирование голоса и визуальная последовательность. Популярность репозитория сама по себе не использовалась как доказательство качества.

## Что загружено

Полные папки выбранных навыков, включая ссылки на локальную документацию, справочные файлы, поставляемый скрипт и лицензии MIT. У каждого пакета есть источник и фиксированный коммит в [installed.json](installed.json). Результаты проверки файлов находятся в [verification.json](verification.json).

Навыки зарегистрированы в текущей рабочей среде Codex в `/home/agent/.codex/skills/`. Это инструкции и рабочие материалы для агента, а не локальные модели генерации и не приложения iOS. Перенос репозитория в новую среду сам по себе не подключает облачные сервисы.

## Что понадобится для создания двойника

- Для HeyGen — подключённый HeyGen MCP или настроенная официальная CLI и доступ к функциям аватара/видео.
- Для голоса — подключение ElevenLabs и тариф с нужной операцией. Ключи вводятся в настройках подключения/среды, не в переписке и не в этом репозитории.
- Для цифрового двойника — выбранные вами фото/видео и запись собственного голоса; при фактическом запуске проверяются актуальные требования сервиса.
- `character-consistency` готовит промпты и референсы. Он сам не генерирует картинки и не гарантирует абсолютного совпадения внешности.

Сам аватар, голосовой клон и платные генерации в этой задаче не создавались. Подключения HeyGen и ElevenLabs для генерации ещё не проверены. Их API, тарифы и доступные модели проверяются перед использованием.

## Порядок работы

1. Собрать ваш согласованный визуальный референс и образ.
2. Создать аватар через `heygen-avatar`.
3. Создать голосовой клон через `elevenlabs`, затем проверить короткую озвучку через `text-to-speech`.
4. Использовать `character-consistency` для референсов следующих сцен.
5. Собрать первый тестовый ролик через `heygen-video` и оценить внешность, голос и синхронизацию.

В репозитории находятся только общедоступные навыки и документация. Личные записи, фото, ключи доступа и данные цифрового двойника сюда не загружались.
