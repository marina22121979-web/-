# Edit Davinci Video

1. Inspect the existing dialogue edit and preserve timing, synchronization, intentional changes, and existing markers.
2. Use the screen-recording skill for moving screen footage and use native Inspector controls for camera framing; review actual frames rather than copying coordinates.
3. Use authentic source images or screenshots where requested. Place additional visuals as separate editable clips on the next available track and avoid unsolicited titles or labels.
4. Check continuous visual coverage, clip boundaries, project frame rates, and saved state. Render only when requested or when a targeted quality check is necessary.
