# Render Davinci Video

1. Render only when requested or when a small targeted quality check is necessary. Save versioned outputs in the project delivery folder.
2. Inspect source resolution, codec, bitrate, and frame rate. Match timeline and playback rates independently, including fractional frame rates.
3. For a typical delivery, use the requested codec and resolution; compare a short native render with original detail at full resolution and adjust bitrate for acceptable visual quality and practical size.
4. Verify the final file duration, dimensions, frame rate, actual bitrate, audio, and playback. Review any screen footage for private material before final sharing and follow the user’s instructions for handling it.
