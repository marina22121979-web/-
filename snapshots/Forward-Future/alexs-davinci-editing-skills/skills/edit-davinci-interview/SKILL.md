# Edit Davinci Interview

1. Preserve the conversation and choose complete, natural takes using a transcript and waveform.
2. For remote interviews, use a balanced split screen or the layout requested, matching apparent head size and eye line while respecting each source aspect ratio.
3. For in-person multicamera interviews, cover each editorial cut with a change to a different physical camera angle. Preserve continuity and sync.
4. Treat each speaker independently for noise and loudness, verify transitions and natural pauses, and save a recoverable editable project.
