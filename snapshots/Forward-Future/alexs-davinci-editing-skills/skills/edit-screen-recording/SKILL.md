# Edit Screen Recording

1. For a visual pass, use native Edit Inspector Zoom and Position so the relevant application content fills the shot and unrelated desktop areas stay outside the canvas.
2. Keep all screen Crop values at zero, preserve aspect ratio, source motion, synchronization, and relevant content. Do not replace moving footage with screenshots or isolated panels unless requested.
3. Compose around any camera overlay and inspect multiple real frames as content moves. Avoid hiding relevant controls or text.
4. Setup, sync, audio, and first-dialogue-only tasks do not authorize a visual pass. Follow current explicit directions.
