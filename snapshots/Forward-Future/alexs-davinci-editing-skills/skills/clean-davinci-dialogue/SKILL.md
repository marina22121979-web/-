# Clean Davinci Dialogue

1. Inspect the source audio and retain an unprocessed copy. Set the project and playback rates to match the primary footage.
2. Build a reusable editable Fairlight voice chain using appropriate noise reduction, expansion, equalization, compression, and limiting. Adjust by listening to the actual speaker rather than assuming one preset fits all.
3. Preserve natural breathing and consonants; compare processed and original audio, check loudness and peaks, and avoid pumping or metallic artifacts.
4. When a continuous processed file is needed before cutting, render it at the source sample rate with sufficient bit depth, measure alignment against the original, and retain the editable preparation timeline.
