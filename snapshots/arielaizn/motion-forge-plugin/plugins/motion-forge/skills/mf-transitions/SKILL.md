# mf-transitions · המעבר הוא רגע

סרט דוגמה: `../motion-forge/studio/gallery/13_transitions.html`. כלים: `scenes`, `FX.motionBlur`, `FX.matte`, `P.*`, `CAM.shake`, `E.whip`.

## החוק
סרט טוב בנוי מחיתוכים פשוטים על הביט, ו**מעבר-גיבור אחד** שמתוכנן כגיאומטריה: נקודה בסצנה A שממופה לנקודה בסצנה B.
כתוב אותו במפורש לפני הקוד: "העיגול הכתום (540, 960, r=80) הופך לשמש של הסצנה הבאה, באותו מקום ובאותו גודל".

## המנגנון
שתי סצנות פעילות בחלון החפיפה (0.25 עד 0.6 שניות). `p` מ-0 ל-1 בחלון, עם `E.whip` או `E.inOutExpo`:
```js
function transition(c, t, a, b, t0, dur, kind) {
  const p = prog(t, t0, t0 + dur, E.whip);
  if (p <= 0) return a(c, t); if (p >= 1) return b(c, t);
  TRANSITIONS[kind](c, t, p, a, b);
}
```

## הקטלוג
| מעבר | גיאומטריה | סאונד |
|---|---|---|
| **Whip pan** | שתי הסצנות זזות יחד אופקית (A יוצאת, B נכנסת) עם `FX.motionBlur` ב-shutter גבוה באמצע | `A.whoosh(t0 - .15, dur + .2)` |
| **Match cut** | אובייקט באותו מיקום, גודל ומהירות בשתי הסצנות. החיתוך עצמו חד, בלי אפקט | `A.hit` קטן או כלום |
| **Zoom-through** | scale של A גדל פי 8 עד 20 לתוך אובייקט (חלון, עין, מסך) עד שהוא ממלא את הפריים, ובתוכו B כבר רצה | `A.riser` קצר + `A.impact` |
| **מסכת צורה** | צורה (עיגול, ריבוע מסובב, לוגו) גדלה מנקודה ומגלה את B דרך `FX.matte` | `A.swish` |
| **בלוקי צבע** | 2 עד 3 מלבנים בצבעי המותג מכסים ומפנים את המסך, 60ms ביניהם | `A.whoosh` |
| **Liquid wipe** | גבול בצורת גל (`P.wave`) או blob שמתפשט, עם קצה מבריק | `A.slide` |
| **Glitch cut** | 3 עד 5 פריימים של `FX.glitch` חזק, ו-B מופיעה בתוך הגליץ' | `A.glitch` |
| **Flash** | לבן או צבע בהיר ל-2 פריימים, B מופיעה עם scale 1.04 → 1 | `A.impact` |
| **Push** | B דוחפת את A החוצה באותו כיוון, 0.4s ב-`E.snappy` | `A.swish` |
| **Spin** | סיבוב של 90 עד 180 מעלות עם blur סיבובי (motion blur) | `A.whoosh` |
| **Light leak** | גרדיאנט חם עובר על המסך ב-`lighter` ומכסה את החיתוך | `A.shimmer` |

## פרטים שעושים את ההבדל
- **Motion blur באמצע המעבר בלבד**: shutter עולה עם המהירות ויורד כשהיא יורדת.
- **המשכיות כיוון**: יציאה ימינה = כניסה משמאל. אם A זזה למעלה, B ממשיכה את אותה תנועה.
- **רעידה קטנה בנחיתה** (`CAM.shake` עם decay של 0.3 שניות) נותנת משקל.
- **הסאונד מתחיל לפני התמונה**: whoosh שמתחיל 0.15 עד 0.3 שניות לפני אמצע המעבר.
