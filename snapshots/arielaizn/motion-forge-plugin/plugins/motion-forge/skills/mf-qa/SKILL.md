# mf-qa · להסתכל באמת

לא מוסרים סרט שלא ראית. הכלים: `render.mjs` בסטודיו.

## הסבב (לפחות פעמיים)
1. `node render.mjs films/X.html --qa` → `out/X-qa.json` + `out/X-grid.jpg`. קרא את ה-verdict ופתח את הגריד.
2. **הגריד (24 תאים):** האם כל תא מובן לבד בגודל תמונה ממוזערת? האם יש תאים כמעט זהים ברצף (סצנה שעומדת)?
   האם טקסט קריא ב-240px? האם הפריים הראשון יפה מספיק לתמונה ממוזערת?
3. **סטריפ לכל רגע מהיר:** `--strip <frame>,12` סביב מעבר, נחיתה, חשיפה. חפש: קפיצות (אלמנט מופיע בלי תנועה),
   overshoot חסר, מגע שלא נוגע, motion blur שבור, פריים ריק באמצע מעבר.
4. **פריימים מלאים:** `--only 0,<שיא>,<סוף>` ובדוק חדות, טקסטורות, קצוות, עברית (כל אות, כל מילה).
5. תקן, ורנדר את מה שהשתנה בלבד (`--from a --to b` לטווח) לפני סבב נוסף.

## מה ה-verdict אומר
| הודעה | משמעות | תיקון |
|---|---|---|
| `FROZEN a-b` | שום דבר לא זז שנייה ומעלה | drift ברקע, נשימה, שכבה שזזה; או `holds: [[a,b]]` אם זו עצירה מכוונת |
| `BLANK a-b` | מסך שחור או לבן | בדרך כלל סצנה שלא צוירה בחלון ב-`scenes`, או אלפא 0 |
| `FLASH RISK` | יותר מ-3 קפיצות בהירות בשנייה | רכך הבזקים, הורד ל-35 אחוז, הפרד ביניהם |
| `THUMBNAIL` | פריים 0 כמעט ריק | התחל את הסרט עם הנושא כבר במסך |
| `AUDIO GAP` | שקט מעל 1.5 שניות באמצע | גרוב שנגמר מוקדם, או `A.silence` ארוך מדי |
| `LOW MOTION` | הסרט מרגיש כמו מצגת | יותר תנועה משנית, מצלמה, stagger |

## בדיקת "רמת אפטר" (תסתכל על הגריד ותענה בכנות)
1. יש easing על כל תנועה ו-overshoot על נחיתות?
2. יש שלוש שכבות עומק ותנועה בכל אחת?
3. יש רגע גיבור אחד ברור?
4. כל חיתוך וחשיפה יושבים על ביט, עם צליל?
5. הפלטה עקבית (3 עד 5 צבעים) והטקסט קריא בגודל טלפון?
6. החומר (בסגנונות עבודת יד) מזוהה מפריים אחד?
7. הסוף מחזיק מספיק זמן (לפחות 1.2 שניות) ונקי?
תשובה שלילית אחת = עוד סבב.

## רינדור סופי
```bash
node render.mjs films/X.html                  # MP4 1080p עם פסקול (-14 LUFS)
node render.mjs films/X.html --gif            # + GIF לתצוגה מקדימה
node render.mjs films/X.html --alpha          # MOV שקוף לאוברליי
ffprobe -v error -show_entries format=duration:stream=codec_type,width,height -of compact out/X.mp4
```
בדיסק מלא: הרינדור מזרים פריימים ל-ffmpeg ולא שומר אותם, אבל `--keep-frames` כן כותב PNG לכל פריים.
סרט ארוך ואיטי: `--workers 4` (ברירת המחדל היא חצי מהליבות, עד 4).

## דטרמיניזם
אם פריים נראה אחרת בנגן ובקובץ: רנדר אותו לבד (`--only f`) והשווה לגריד. הבדל = מצב שנשמר בין פריימים או רנדומליות.
