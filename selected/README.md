# Пять установленных навыков

Набор выбран для обработки личных видео в этой Linux-среде: без Premiere, CapCut и облачных API.

| Навык | Для чего | Команда в текущей среде |
| --- | --- | --- |
| [ffmpeg-skill](ffmpeg-skill/SKILL.md) | Монтаж, склейка, звук, фильтры, проверка видео | `video-tool probe INPUT --json` |
| [color-grade](color-grade/SKILL.md) | Анализ цвета, LUT для уменьшения красноты кожи | `color-grade FRAME.png --transfer display --emit fix.cube` |
| [color-grading](color-grading/SKILL.md) | HDR с iPhone → SDR, LUT и цветокоррекция | `color-grading run REQUEST.json --json` |
| [subtitle-skill](subtitle-skill/SKILL.md) | Генерация, проверка и встраивание готовых субтитров | `subtitle-skill run REQUEST.json --json` |
| [platform-spec-export](platform-spec-export/SKILL.md) | Экспорт H.264/AAC, изменение формата кадра | `platform-spec-export INPUT.mp4 --platform square --outdir OUT` |

Установлены **в среду обработки видео**, а не в iOS или учётную запись ChatGPT целиком. Файлы пакетов находятся в `selected/`, ссылки для обнаружения Codex — в `/home/agent/.codex/skills/`. Вспомогательные команды доступны через `/home/agent/.local/bin/`. При открытии новой среды навыки и зависимости нужно установить там заново. Наличие на GitHub само по себе не активирует навык в каждом чате.

## Среда

- FFmpeg/ffprobe 7.1.5.
- Python 3.12; отдельное окружение `/workspace/video-tools/.venv`, использующее доступные Pillow, NumPy, PyYAML.
- `color-grading-skill` 0.4.0 и `subtitle-skill` 0.4.1 установлены как Python-пакеты.
- Ruby 3.3.8 установлен локально в `/workspace/video-tools/ruby`; системные каталоги не изменялись.
- Команды `color-grading` и `subtitle-skill` настроены на сохранённый `ffmpeg-skill`.
- Команда `color-grade` запускает анализатор с нужным Python и Ruby.

Для подбора LUT на CPU используйте уменьшенный диагностический кадр (`video-tool look INPUT --at 1 --width 256 -o frame.png --json`): подбор по большому кадру может быть медленным. В проверке подбор на кадре шириной 64 пикселя прошёл; первый прогон на полном превью превысил 120 секунд.

## Ограничения

Коррекция красноты через LUT меняет подходящие по цвету пиксели; это не удаление морщин, не локальная ретушь с отслеживанием лица и не увеличение глаз. Автоматическое распознавание речи и дополнительные модели машинного перевода не устанавливались. Субтитры работают с готовыми текстами и таймкодами.

H.264/yuv420p/MP4 подходит для воспроизведения на iPhone, но установка навыков не создаёт внешнюю ссылку на видео. Реальный iPhone в этой среде недоступен для проверки.

## Происхождение и проверка

У каждого пакета есть `UPSTREAM.json` с исходным репозиторием и фиксированным коммитом. Исходные лицензии сохранены. Дерево `selected/` содержит рабочие скрипты и ссылки на документацию, а не только снимки SKILL.md.

[installed.json](installed.json) описывает установку. [verification.json](verification.json) содержит результаты выполнения на синтетическом видео. Проверено 16 пунктов, включая планирование и реальное кодирование, генерацию и автоподбор LUT на малом кадре, наложение LUT, русские субтитры, экспорт и визуальный просмотр. При изменении формата кадра выбрано заполнение с размытием вместо центральной обрезки, чтобы сохранить субтитры целиком. Личное видео пользователя для этой проверки не использовалось и на GitHub не загружалось.
