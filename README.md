## Как пользоваться

Откройте нужный раздел и выберите навык. В таблице есть сохранённая инструкция и ссылка на оригинальный проект. Для установки берите полный пакет из оригинального проекта с его scripts, references, assets и зависимостями. Здесь сохранены файлы инструкций и лицензии, а не все вспомогательные файлы проектов.

Навыки не установлены и автоматически не активируются. Некоторые требуют локальную монтажную программу, MCP-сервер, API-ключ или платный сервис. Наличие инструкции не означает, что такое средство доступно в текущем чате. Тестов монтажа и рендера по этим навыкам не проводилось.

## Что проверено

- Наличие файлов SKILL.md в деревьях исходных репозиториев.
- Побайтовое совпадение сохранённых файлов с Git blob SHA-1 исходников.
- Повторы одного blob внутри репозитория сокращены; варианты между разными проектами сохранены с атрибуцией.
- Обычные навыки разработки и нерелевантные результаты поиска исключались. Это отбор, а не полная ручная проверка каждой инструкции.

## Источники и лицензии

- [sources.json](sources.json): запросы, найденные репозитории, ветки, SHA деревьев и файлов.
- [catalog.json](catalog.json): машиночитаемый каталог.
- [LINKS_ONLY.md](LINKS_ONLY.md): дополнительные навыки без копии.
- [licenses/](licenses/): исходные лицензии и уведомления.
- [VERIFICATION.json](VERIFICATION.json): результаты проверки и точные счётчики.

Авторство и условия использования каждого навыка принадлежат его авторам. Общей лицензии, заменяющей условия исходников, у сборника нет. Наличие лицензии проекта не отменяет специальных условий отдельных файлов и сервисов.

## Границы поиска

Проверено 12 запросов GitHub, до 30 результатов каждого запроса, плюс официальный репозиторий remotion-dev/skills. Часть выдачи может измениться, а некоторые репозитории недоступны. Все возможные навыки GitHub перечислить и проверить невозможно; эта подборка не заявляет полноту. Категории назначены по названию проекта и навыка; возможны пересечения и неточности.

Для повторной проверки файлов и сборки индекса:

```sh
python tools/build_catalog.py
```

Поиск и копирование выполнены без запуска сторонних скриптов и установки скачанных навыков.
